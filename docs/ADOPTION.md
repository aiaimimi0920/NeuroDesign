## 判定标准

- **已验证**：真实调用点使用标准包，没有同一控件的手写交互或旧皮肤接管；有相关行为、消费构建和必要的浏览器证据。
- **部分迁移**：模块已用标准包，但仍有应迁移的基础控件、弹窗、状态或样式。仅存在 import 不算完成。
- **待迁移**：仍由应用实现通用控件。按直接依赖和业务契约成组推进，不做只改标签的批量替换。
- **应用保留**：确属业务或宿主设施；保留原因应具体，不以文件大、测试难或存在旧门禁为排除理由。
- 原生标签搜索仅用于找候选，不能作为完成率。隐藏文件输入、技术绘图节点与通用按钮要人工区分。
- 选择更新应保留 DOM、焦点和几何；弹层要验证初焦、返回、嵌套 Escape、busy、窄屏、主题和滚动清理。
