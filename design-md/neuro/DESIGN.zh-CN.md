# neuro

neuro 使用近黑中性表面、信号黄强调、小圆角和连续边界，通过克制的色彩、明确的层级与稳定的几何组织信息。

## 1. 主题定义

本规范定义配色、排版、几何、间距、控件状态与交互表达，不限定产品类型、业务领域、页面用途、信息架构或技术框架。

根据实际内容选择页面结构和控件，只为已有功能应用相应规则；不因主题示例包含某种布局或功能，就为目标产品添加相同内容。保持业务字段、权限、流程与内容含义不变。

## 2. 设计原则

1. **任务先于界面外壳。** 当前资源、操作和结果应当直接可见。面板用于建立内容归属或滚动边界。
2. **每个任务上下文只有一个主操作。** 信号黄标记主操作或当前状态，不用于铺满标题和图标。
3. **连续表面，按需分组。** 通过对齐、间距、细分隔线和必要容器建立关系，避免把不同层级都做成等权卡片。
4. **中性色承担主体。** 黑、灰与正文构成主要界面，语义色提供少量有意义的信号。
5. **常态即可辨认。** 控件、次级文字、禁用状态与权限提示不依赖悬浮才看得清。
6. **密度取决于上下文。** 28px 设置控件与 36px 主操作可以共存，不能平均成一个全局强制尺寸。

### 界面文案

**不使用装饰性英文标题。** 只保留能定位当前页面、对象或真实分组的标题，使用目标语言的自然写法。不为设计感额外添加英文眉题、全大写微标签、斜线分隔的伪层级或口号式副标题。这不是禁止英文界面、技术缩写或真实标识符。

**默认不添加解释性文案。** 按钮、字段或标题已能表达含义时，不再附加用途说明、操作教程、重复标签或理念标语。先改善命名、分组和状态表达，不用一段说明补偿不清晰的控件。

只有省略后会造成歧义、操作失败或风险时才保留短提示，例如非显然的输入格式/单位、错误与恢复方法、权限限制、破坏性操作后果及必要的演示边界；按需就近呈现，不为每个控件固定预留说明行。图标的可访问名称和必要字段标签不能删除。设计文档与控件浏览页可以保留必要的规格说明，但不应把它们复制成产品界面的常驻解释。

## 3. 配色与语义

### 深色模式——默认

| 角色 | 色值 | 用途 |
|---|---|---|
| 主背景 | `#06080d` | 应用外层背景 |
| 侧栏 | `#070a0f` | 导航与标题栏 |
| 一级表面 | `#090c11` | 连续工作主板 |
| 面板 | `#0e1218` | 相关内容、菜单、弹窗 |
| 控件 | `#111720` | 输入框与次级操作 |
| 控件悬浮 | `#18222c` | 控件抬升状态 |
| 正文 | `#f7f8ef` | 主要标签和内容 |
| 次级文字 | `#929a9f` | 说明与元数据 |
| 细分隔线 | 正文色 12% 透明度 | 建立边界，不做厚重框线 |
| 信号黄 | `#d9ff38` | 主操作、激活、焦点、需要注意 |
| 信号绿 | `#22c55e` | 品牌身份、在线、成功、完成 |
| 信息蓝 | `#06b6d4` | 链接、技术信息、同步 |
| 危险红 | `#f43f5e` | 错误、破坏性操作、高风险 |

黄色与绿色各只有一个主色，状态通过派生得到，不引入竞争品牌色：

~~~css
--primary-hover: color-mix(in srgb, #d9ff38 86%, white);
--primary-pressed: color-mix(in srgb, #d9ff38 82%, black);
--on-primary: color-mix(in srgb, #d9ff38 14%, black);
--signal-soft: color-mix(in srgb, #d9ff38 12%, #0e1218);
--border: color-mix(in srgb, #f7f8ef 12%, transparent);
--signal-border: color-mix(in srgb, #d9ff38 42%, var(--border));
~~~

颜色之外必须配合文字、图标、勾选、边线或结构。绿色不是默认主按钮底色，普通次级操作默认采用中性控件，而不是一律用蓝色。

### 数据变化不等于结果状态

增加/减少不自动等于成功/失败。显示延迟、费用、内存或吞吐变化时，用带正负号的变化值或方向配合单位和比较基准表达；是否改善由真实业务判断。内存增加不是任务成功，延迟下降也不是失败。没有定义好坏含义时使用中性文字，不建立“上涨绿、下降红”的通用规则，也不新增竞争趋势色。

### 小范围反色部件，而非强制白卡

小面积反色部件使用 `#f3f5f1` 背景与 `#20252b` 文字，适用于 tooltip、开关滑块或需要独立底色的标记。主要容器遵循中性表面层级，不通过大面积白色卡片表达选中或焦点。

## 4. 排版

界面字体栈：`"Bahnschrift", "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。

技术字体栈：`"Cascadia Mono", "JetBrains Mono", Consolas, monospace`。这些是回退偏好，不代表已附带字体文件。

| 角色 | 实用基准 | 处理方式 |
|---|---|---|
| 应用页面标题 | 20–24px | 600–650，不做巨型 hero |
| 分区标题 | 14–16px | 600–650 |
| 正文 | 13–14px | 常规字重，保留可读行高 |
| 标准操作 | 13px，字重 800 | 强调明确，文案简短 |
| 紧凑设置/标签页 | 12px | 约 550–600 |
| 辅助元数据 | 11–12px | 次级色，但须保持对比 |
| 标识符、代码、体积 | 11–13px | 等宽、表格数字 |

这些数值是默认排版基准。支持目标平台的字体回退、用户字号与缩放偏好，不以固定像素阻止可读性调整。

界面标题与分组标签采用自然大小写和字距，不以全大写、等宽眉题或大字距制造设计感；密集设置页不使用营销展示字体。

## 5. 几何与间距

| 元素 | 规则 |
|---|---|
| 按钮/导航 | 4px 圆角 |
| 输入框/通用面板/弹窗 | 8px 圆角 |
| 侧栏/主板 | 直角连续边界，不加悬浮卡片阴影 |
| 标准按钮 | 最小高度 36px，水平内边距 12px |
| 常规输入框 | 垂直 10px、水平 12px 内边距，高度随字体度量确定 |
| 紧凑设置输入框/按钮 | 高 28px，字号 12px，水平内边距 8–10px |
| 常规面板 | 内边距 18px |
| 工作区内容 | 间隔 14px，外侧内边距约 16–20px |
| 弹窗 | 内边距 24px，内容间隔 16px |
| 边框 | 通常 1px |
| 轻表面阴影 | `0 2px 8px rgb(0 0 0 / 14%)` |

默认使用 4/8px 小圆角体系。圆轨道开关是明确的控件变体，不把其胶囊几何推广到按钮、输入框或所有容器。

## 6. 布局语法

页面结构由内容和任务决定，不要求固定的侧栏、标题栏、主板或详情区组合。需要这些区域时，优先采用连续边界、紧凑分区和明确的滚动归属。

导航侧栏可从 **212px 宽度、38px 上下文栏、30px 导航行及至少 46px 内容标题区** 起步，再根据文字、操作和可用宽度调整；这些是可选布局基准，不是必需的页面骨架或窗口尺寸。

- 将主要可用宽度交给当前任务。
- 搜索、筛选、视图控制和上下文操作放在一起。
- 数据优先使用稳定行；内容确实受益于缩略图时再使用网格。
- 详情检查器直接呈现属性，不把每项属性再包成一张卡。
- 长列表与检查器采用明确滚动边界，避免局部展开改变整个壳层。
- 窄屏时折叠或移动导航、堆叠详情，而不是整体缩小文字。
- 普通浏览器网站不伪造一排持续占位的原生窗口按钮。

### 长表格

需要跨行比较的长表格，在既有有界区域内滚动表体时保留列标题可见。固定表头具有不透明表面、正确层级，并与表体列对齐。窄宽时按业务决定列优先级或采用局部横向滚动，不整体缩字，也不把每行都拆成大卡片。这是长表变体，不要求短列表额外增加常驻表头或滚动容器；冻结首列是另一项需要任务依据的选择。

### 内容预览保真

截图、图表、示意图和捕获内容是用户内容，不是主题装饰。检查/编辑预览保持宽高比与关键边缘，主题色用于周围控件、边界和选择标记，不任意给内容染色、拉伸或旋转。用于浏览的缩略图可在有利于识别时明确裁切；检查预览通常完整呈现内容。按任务选择适配/缩放方式，不对所有图片统一套用 `cover` 或 `contain`。中性留边优于内容失真或技术细节被隐藏。

## 7. 控件配方

| 控件 | 外观与行为 |
|---|---|
| 主按钮 | 黄底深字、4px 圆角，悬浮/按下色从主色派生，每个任务上下文只设一个。 |
| 次级/描边按钮 | 中性控件底、细边框、正文色；悬浮提升表面和边界，不提升语义优先级。 |
| 安静/图标操作 | 透明底，图标有语义标签，悬浮与键盘焦点可见；26–28px 壳层操作是合理场景。 |
| 破坏性操作 | 红字、红色派生边线与弱底；有意义的删除通过页面内弹窗确认。 |
| 禁用控件 | 次级文字、控件底、稳定边框，不争抢阴影；不将整个元素淡到难以阅读。 |
| 输入框/多行框/下拉框 | 标签和边界常态可见，控件底与正确文字/placeholder，黄色焦点；错误有红边和就近说明。 |
| 复选/单选/滑杆 | 黄色语义强调，保留原生键盘操作，控件形态本身传达状态。 |
| 开关 | 圆轨道是受支持的例外，小反色滑块在明暗模式中都可辨。 |
| 导航 | 当前项有黄色派生底/边框与内侧信号线，图标和标签层级清楚。 |
| 标签页 | 紧凑中性项，当前项使用信号弱底和强边框；tablist 支持方向键，用于切换内容面板。 |
| 面板/卡片 | 深面板、8px 圆角，需要时有轻阴影；连续主板不是悬浮圆角卡。 |
| 数据行 | 列关系清楚、间距稳定，选择通过控件/标记加表面变化表达；行高按内容密度确定，同一视图中保持一致。 |
| 状态/通知 | 短文字加图标、语义强调和中性/弱底；持久错误不能只留在 toast 中。 |
| Tooltip | 小反色面，深色模式下用深字；提供补充信息，不承担理解控件所必需的信息。 |
| 弹窗/菜单 | 不超视口，层级正确、内部可滚动；操作通常置于末端并围绕任务组织。 |
| 空/加载/失败 | 给出原因或下一步，不伪造已连接、已上传或成功状态。 |

优先复用目标项目已有控件，按本规范设置视觉和交互，不绑定特定框架、组件库或 CSS 类名。

### 选择控件的取舍

| 场景 | 优先形式 | 规则 |
|---|---|---|
| 少量、短名称的多选一 | 分段单选 | 如关闭/开启、100%/110%/125%/150%；同组只能选一项，采用原生 radio 语义，不冒充标签页或多个独立开关。 |
| 选项较多、名称较长或横向放不下的多选一 | 单选下拉框 | 优先使用 `select`，不为展示全部选项而挤压界面。 |
| 少量多选 | 平铺复选框组 | 短标签横排，较长标签或窄区域竖排；每项独立勾选，允许同时选多项或全部不选。 |
| 多选较多或空间有限 | 下拉多选 | 展开后是复选框列表，不是单选菜单；勾选不自动关闭，触发器以固定单行显示已选数量，面板内部滚动。 |

分段轨道使用中性控件底，选中项使用信号黄派生底/边框/内侧标记，保留 4px 默认控件圆角。复选框与下拉多选沿用相同主题语义。

所有选择态必须保持几何稳定：不因勾选改变 padding、边框宽度、字号/字重、列宽或行高。选中线使用不占布局空间的内阴影/轮廓，或提前预留边框。只更新选择属性和状态样式，不因一次勾选重建整张表；批量操作使用既有区域，不突然插入一行推开列表。

### 可复制技术值

对于经常需要复制的 ID、端点、路径、命令或配置片段，在值旁提供低强调复制操作，不为所有文字都增加按钮。单个值不必再包代码卡，多行片段可以使用独立代码容器。操作沿用 4px 控件圆角，值本身保持可读、可选择。

- 预留稳定的操作位，真实复制成功后短暂原位替换为勾号等反馈；不推动数值，不添加“点击复制”等说明，不为每次常规复制都弹 toast。
- 明确复制完整值还是显示/脱敏值，不得绕过产品权限暴露隐藏密钥。失败时在发生处提供必要短反馈，不把复制失败显示成成功。
- 提供可访问名称和键盘操作，成功/失败可被辅助技术获知，不只依赖图标。验证目标宿主的剪贴板能力，需要支持本地网页时包含 `file://` 场景。

### 紧凑数值步进器

需要反复微调的数值，可将减号、数值、加号组织在同一紧凑属性行中，适用时允许直接编辑，并将 `px`、`%` 等真实单位与值合组。按上下文采用 28px 紧凑控件基准、4px 操作圆角及既有输入框几何，普通表单仍可保持常规可读尺寸。不替换所有原生数字输入或滑杆，也不向已足够的控件重复堆加步进按钮。

- 由产品定义范围、步长、精度、空值语义及边界/越界行为；到达上限或下限时只禁用对应增减操作，不静默替换成任意默认值。
- 适用时保留原生数字输入语义、直接输入和键盘操作，增减按钮有可访问名称，不让整个组合只能靠鼠标操作小按钮。
- 为预期数字位数和单位预留宽度，增减、跨位数、聚焦或禁用时不改变组合尺寸、不推开相邻属性。单位是字段信息，不是额外解释段落。

### 核心控件状态配方

按控件实际行为使用下列状态，不要求每个控件具有全部状态。悬浮、按下、键盘焦点、选中和禁用含义不同；焦点可以与选中或错误并存。

| 控件 | 常态 | 悬浮/按下 | 持续状态或错误 | 键盘焦点 | 禁用/加载 |
|---|---|---|---|---|---|
| 操作按钮 | 按主操作、中性或破坏性配方 | 派生表面/边框；主按钮使用黄派生悬浮/按下色 | 只有真实切换按钮使用持续按下态，不把一次操作完成画成选中 | 可见的 2px 信号轮廓 | 次级但可读的控件，阻止不可用操作；真实加载预留反馈空间 |
| 文字/数字/下拉输入 | 控件底、可见边框与标签 | 不位移、不改变 padding | 只读仍可选取；无效有危险边界和必要的就近错误 | 信号边界与可见轮廓；错误仍可辨 | 可读但不可用；只读不等于禁用 |
| 复选/单选/开关 | 可辨认的原生或等价控件 | 命中区域与几何保持稳定 | 勾号、圆点或滑块位置配合信号色 | 实际控件上的焦点可见 | 不可操作但不抹去当前值；不虚构通用加载态 |
| 分段单选 | 中性轨道，预留边框，各项处理一致 | 控件悬浮面，字重稳定 | 选中项使用信号弱底、信号边框和内侧标记 | 可见分段上的轮廓 | 次级但可读，不可通过禁用项改变选择 |
| 数据行 | 稳定列与中性表面 | 只改变悬浮表面 | 复选/标记配合选中表面或内侧边线 | 实际交互单元/控件上的焦点可见 | 只禁用不可用操作，保留行内容 |
| 菜单/下拉多选 | 中性触发器，面板关闭 | 交互行悬浮但不位移 | 展开触发器有信号边界；勾选项保留勾号与弱底 | 触发器/选项焦点可见，Escape 返回触发器 | 不可用项不能执行；不把无结果混同加载 |

边框、padding、字号/字重、行高与反馈位在这些状态之间保持几何稳定。检查深浅色和减少动效下实际使用的状态组合，不为填满状态矩阵而虚构控件行为。

空态使用简短、真实的状态标题；只在确有必要时附带操作或缺失前提，不追加口号或重复操作说明。整页空态可以居中并保留适度高度；卡片、范围栏和内嵌列表使用紧凑行式空态，不套用整页最小高度，不撑开业务卡片或推移固定操作。

## 8. 交互契约

- 提供可见的 2px 键盘焦点、正常 Tab 顺序和语义标签。
- 模态框支持 Escape、初始焦点、键盘焦点约束、背景滚动锁定，以及关闭后回到触发项或仍存在的等价项。
- 菜单支持外部交互与 Escape 关闭，操作可通过键盘到达。
- tablist 支持左/右方向键及 Home/End，只有当前标签进入普通 Tab 序列。
- 分段单选保留原生 radio 的方向键和单个 Tab 入口；复选框使用 Tab/Space。下拉多选支持 Enter/Space 展开、Tab 到选项、Space 勾选，Escape 关闭并回到触发器；外部点击关闭，展开面板不参与页面排版。
- 悬浮主要改变表面和边框，不推动相邻元素，不动画化整个布局。
- 短状态过渡约 140–200ms，尊重 `prefers-reduced-motion`。
- 长名称按意图换行或截断，不隐藏唯一标识或唯一操作。
- 选中、错误、进度都有颜色以外的解释。
- 状态反馈与真实操作结果一致，不把未执行或失败的操作显示为成功。

## 9. 浅色模式

| 角色 | 浅色值 |
|---|---|
| 主背景/表面/面板 | `#edf1e4` / `#f8faf3` / `#ffffff` |
| 侧栏 | `#e4e9dc` |
| 控件/悬浮 | `#f1f4ea` / `#e7ecdf` |
| 正文/次级文字 | `#10150e` / `#5d6659` |
| 细分隔线 | 正文色 16% 透明度 |

保留基础信号色，但通过与深色正文混合加深信号**文字**：黄 34%，绿和蓝 52%，红 68%。黄色主按钮仍配深字。反色 tooltip 切换为 `#1b2318` 背景、`#f4f7ef` 文字。仅切换配色，保留既有密度、几何和信息层级。

## 10. 结构图形与禁止方向

三角、切角、斜线、网格和同心圆可用于**局部结构语义**，例如连接示意或有含义的标记，不是必选背景。

避免紫粉替代配色、发光球、全局玻璃模糊、超大圆角卡片、全控件胶囊化、重复容器和等权指标卡片墙。允许克制的表面阴影、模态遮罩模糊与圆轨道开关；局部效果必须用于层级或控件语义，不扩散为装饰。

## 11. 可直接使用的实现提示词

> 文案约束：不添加装饰性英文眉题、全大写微标签或口号副标题。默认不添加解释性文案，不重复解释含义清楚的按钮和字段；仅保留理解任务、避免错误或风险所必需的简短提示、字段标签和可访问名称。

> 选择约束：少量短选项的单选可用主题色分段 radio，选项多或放不下时优先下拉；多选使用横/竖排复选框组，或展开复选框列表的下拉多选。勾选只改变状态，不改变控件几何、重建整张表或推开列表。

> 细节约束：按任务需要提供技术值就地复制及真实反馈、带明确单位/边界且宽度稳定的紧凑数值步进器；长表在局部滚动中保留表头，检查预览保持内容保真。数据变化方向不等于成功/失败。深浅色均遵循适用的控件状态配方，不为满足配方而新增非必要控件或业务能力。

> 为目标界面应用 neuro 主题，不改变其业务定义或功能范围。使用准确的近黑中性表面层级、信号黄主操作/激活/焦点、绿色身份/成功、青色信息和红色危险。默认采用 4px 控件及 8px 输入框/面板圆角；常规按钮 36px、上下文设置控件 28px。布局根据实际内容确定，以连续边界和紧凑分组组织信息，不强制增加侧栏、详情区或指标卡片。使用本规范的界面字体栈，技术值使用等宽字体。不增加大白色焦点卡、玻璃背景或装饰霓虹。保留真实业务字段、权限和操作结果，实现必要标签、键盘焦点、Escape、弹窗焦点恢复、空/错误/加载态、响应式滚动及减少动效。复用项目已有组件，不假定特定框架。
