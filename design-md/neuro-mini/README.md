## 使用规范

将所需语言的设计文档交给目标项目中的 AI，或复制为该项目的 `DESIGN.md`。规范只定义主题，不要求目标产品采用预览的业务、页面骨架或功能。使用规范不依赖本仓库的脚本、样本、维护记录或其他主题文件。

## 打开预览

用现代浏览器直接打开控件浏览页或网站示例，无需构建、服务、账号、CDN 或网络字体。复制预览时保留本目录和同级 `_neuro` 目录；`theme.css` 是预览使用的主题变量映射，不是目标项目必须采用的代码接口。

控件页展示配色、排版和可操作状态；网站以项目/资源管理页面演示主题的组合效果。这只是一个使用场景，不是主题的产品定义。

## 演示边界

- 数据为夹具，增删改仅作用于当前标签页，刷新重置；不接入真实账号、文件或后端。
- 只有随附的 640 × 400 SVG 样本具有实际图像预览，其余条目显示预览不可用，不代表支持对应文件格式的解码。
- Columns 使用 1–12、步长 1；Stroke width 使用 0.25–4 px、步长 0.25；Zoom 使用 1–200%、步长 1。它们是演示参数，不是产品字段的统一限制。
- 数值提交时越界夹到边界，非整步值吸附到最近步长，空值或无效输入恢复上次已提交值。Fit 完整呈现样本，显示取整后的实际适配比例。
- 复制完整显示的非秘密 ID，反馈取决于真实 Clipboard API 结果；权限与可用性由浏览器或宿主决定，失败时可手动选取值复制。
- 存储与延迟比较为静态示例，不是实时统计；加载动作只处理演示状态，不代表后端任务。
