# neuro-mini

neuro-mini 使用近黑中性表面、信号黄强调、直角基础控件和紧凑间距，通过连续行、行内属性与少量容器减少界面占用，同时保留可读性和完整状态。

## 1. 主题定义

本规范定义配色、排版、几何、密度、控件状态与交互表达，不限定产品类型、业务领域、页面用途、信息架构或技术框架。

紧凑来自结构、容器和间距的节制，不依赖全局缩放、难读的小字或语义删减。根据实际内容选择布局和控件，保持业务字段、权限、流程与内容含义不变；不为套用主题而添加示例中的功能。

## 2. 设计原则

1. **可用空间是一种资源。** 每条常驻栏、标签、间距和容器都应有任务上的理由。
2. **先压缩结构，再考虑文字。** 先去掉重复标题、多层框和过量内边距，再讨论缩小字号。
3. **默认直角，例外有用途。** 平直边界让控件和行能直接衔接，不依赖装饰性沟槽。
4. **属性靠近任务。** 通过紧凑分组、图标工具、行内值和折叠呈现调整，不为每个调整项开一整页。
5. **不删除语义。** 标签、tooltip、错误解释、选择和键盘焦点仍然存在。
6. **密度按内容调整。** 设置弹窗和长文本可以比工具条宽松，不要求每个控件都只有 24px。

### 界面文案

**不使用装饰性英文标题。** 只保留能定位当前页面、对象或真实分组的标题，使用目标语言的自然写法。不为设计感额外添加英文眉题、全大写微标签、斜线分隔的伪层级或口号式副标题。这不是禁止英文界面、技术缩写或真实标识符。

**默认不添加解释性文案。** 按钮、字段或标题已能表达含义时，不再附加用途说明、操作教程、重复标签或理念标语。先改善命名、分组和状态表达，不用一段说明补偿不清晰的控件。

只有省略后会造成歧义、操作失败或风险时才保留短提示，例如非显然的输入格式/单位、错误与恢复方法、权限限制、破坏性操作后果及必要的演示边界；按需就近呈现，不为每个控件固定预留说明行。图标的可访问名称和必要字段标签不能删除。设计文档与控件浏览页可以保留必要的规格说明，但不应把它们复制成产品界面的常驻解释。

## 3. 配色与语义

### 深色模式——默认

| 角色 | 色值 | 用途 |
|---|---|---|
| 主背景 | `#06080d` | 工具外层表面 |
| 侧栏 | `#070a0f` | 紧凑导航与辅助外壳 |
| 一级表面 | `#090c11` | 主工作区 |
| 面板 | `#0e1218` | 属性、菜单、弹窗 |
| 控件 | `#111720` | 输入与中性操作 |
| 控件悬浮 | `#18222c` | 可辨的交互状态 |
| 正文 | `#f7f8ef` | 内容和控件 |
| 次级文字 | `#929a9f` | 辅助信息 |
| 细分隔线 | `rgba(255, 255, 255, 0.12)` | 小尺度结构边界 |
| 信号黄 | `#d9ff38` | 当前工具、焦点、主任务、注意 |
| 信号绿 | `#22c55e` | 身份、在线、成功、完成 |
| 信息蓝 | `#06b6d4` | 链接、技术信息、同步 |
| 危险红 | `#f43f5e` | 失败和破坏性操作 |

不需要第二种黄或绿来“丰富主题”。激活底色与彩色边框使用透明度或 `color-mix` 派生。

~~~css
--active-background: color-mix(in srgb, #d9ff38 14%, transparent);
--active-border: color-mix(in srgb, #d9ff38 38%, transparent);
--text-secondary: color-mix(in srgb, #f7f8ef 78%, transparent);
--panel-raised: color-mix(in srgb, #111720 98%, transparent);
~~~

菜单、弹窗和固定表头需要稳定可读的背景；不依赖桌面透明能力，也不使用玻璃模糊。需要不透明激活底时，将 12% 信号黄与面板色混合，不引入新的强调色。

同时保留非颜色信号：按下工具、复选框、内侧边线、状态文字或图标。绿色不作为默认主操作色。

### 数据变化不等于结果状态

增加/减少不自动等于成功/失败。显示延迟、费用、内存或吞吐变化时，用带正负号的变化值或方向配合单位和比较基准表达；是否改善由真实业务判断。内存增加不是任务成功，延迟下降也不是失败。没有定义好坏含义时使用中性文字，不建立“上涨绿、下降红”的通用规则，也不新增竞争趋势色。

## 4. 排版

常规工具与设置文字优先使用 `system-ui, "Segoe UI", "Microsoft YaHei", sans-serif`；技术值与标识符使用 `ui-monospace, "SFMono-Regular", Consolas, monospace`。

| 角色 | 工作基准 | 处理方式 |
|---|---|---|
| 紧凑工作区标题 | 14–16px | 600，避免额外高大的 hero |
| 分组标题 | 12–14px | 600 |
| 正文/标准字段 | 12px | 可读行高，约 1.4–1.5 |
| 密集值/说明 | 11px | 需要时使用等宽 |
| 长表单设置标题 | 20px | 阅读型区域保持易读 |
| 小工具图标 | 14px | 次级属性控件 |
| 悬浮工具条图标 | 22.5px | 仅用于命名的悬浮工具条变体 |

小元数据是辅助信息，不能成为操作的唯一解释。界面标题与分组标签采用自然大小写和字距，不使用装饰性英文眉题。不能依靠压缩展示字体、大字距技巧或全局缩放制造密度。

以上是按内容密度使用的排版基准，不强制把全部角色压缩成一种字号；支持平台字体回退、用户字号与缩放偏好。

## 5. 几何、密度与例外

### 默认基础控件

基础圆角为 **`0px`**，背景模糊为 **`0px`**。壳层、通用输入、菜单、列表项和属性控件保持直角。

| 上下文 | 规则 |
|---|---|
| 紧凑属性图标操作 | 24px 宽控件与约 14px 图标 |
| 开关 | 42 × 24px、14px 方形滑块 |
| 标准字段/操作 | 默认基准 28px |
| 紧凑网页输入 | 垂直 4px、水平 8px 内边距 |
| 分组间隔 | 通常 4–8px |
| 面板内边距 | 紧凑属性区约 8–12px |
| 边框 | 通常 1px，不为每个分组再加外框 |
| 紧凑菜单 | 常规最小行高 24px；专用指针工具菜单可按需采用 20px |
| 阅读/设置字段 | 最小高 36px，垂直/水平内边距 8px / 10px |
| 阅读/设置弹窗 | 正文内边距 20px、间隔 16px，头尾垂直/水平内边距 18px / 20px |
| 紧凑面板阴影 | 默认无；悬浮层仍可有克制分离感 |

数据行高度随内容和密度确定，同一视图中保持一致。不能将专用菜单的 20px 行高推广到所有输入框或触屏命中区。

### 悬浮工具条变体

独立悬浮工具条可使用 **9px 外层圆角**、**5px 工具按钮圆角**、**4px 菜单圆角**，外层垂直/水平内边距 **4px / 5px**，无阴影。菜单行仍保持直角。

仅将这些圆角应用于**悬浮工具条变体**，不推广到普通表单、列表或面板；基础控件的直角默认也不取消该变体。

## 6. 布局语法

- 主要内容占主导，常驻外壳必须证明其空间价值。
- 尽量使用简短单行工具组；合并重复身份标签，不删重要状态。
- 优先采用连续行与直接属性列表，不使用每项属性一张卡。
- 高级字段按需展开，常用控件靠近其影响对象。
- 窄工具面与阅读面分开处理，不靠把长表单变得难读实现紧凑。
- 列表和属性区使用明确的局部滚动。
- 窄屏时换行工具组、堆叠或折叠导航，不对应用使用 `transform: scale(...)`。
- 触屏场景可以扩大命中区；桌面紧凑尺寸不能成为牺牲键盘或指针可用性的理由。

页面结构由内容决定，不要求固定的侧栏、工具栏或检查器组合。需要这些区域时按标签、操作和可用宽度确定尺寸，不为装饰性文案预留常驻顶栏，也不强制固定窗口大小。

### 长表格

仅在内容确实需要长多列表格比较时，在既有有界区域内滚动表体并保留列标题可见。固定表头具有不透明表面、正确层级，并与表体列对齐。窄宽时按业务决定列优先级或采用局部横向滚动，不整体缩字，也不把每行都拆成大卡片。小型列表不为满足这个变体额外增加常驻表头或滚动容器；冻结首列是另一项需要任务依据的选择。

### 内容预览保真

截图、图表、示意图和捕获内容是用户内容，不是主题装饰。检查/编辑预览保持宽高比与关键边缘，主题色用于周围控件、边界和选择标记，不任意给内容染色、拉伸或旋转。用于浏览的缩略图可在有利于识别时明确裁切；检查预览通常完整呈现内容。按任务选择适配/缩放方式，不对所有图片统一套用 `cover` 或 `contain`。中性留边优于内容失真或技术细节被隐藏，不能为了让所有预览填满小矩形而牺牲保真。

## 7. 控件配方

| 控件 | 外观与行为 |
|---|---|
| 主操作 | 黄底深字、直角，服务当前任务，不把每个工具图标都做成主操作。 |
| 中性操作 | 控件底或透明底、细边界、可读文字，内边距简短。 |
| 图标/紧凑切换 | 小型方形目标、图标对齐一致，按下态有表面与边框变化，并提供可访问名称。 |
| 悬浮工具 | 使用命名的悬浮工具条变体，当前工具有小型内侧信号轮廓。 |
| 破坏性操作 | 红色派生线/文字/弱底，需要确认时明确操作对象、后果与取消入口。 |
| 禁用控件 | 次级但可读，边界稳定，无发光，仍能辨认控件类型。 |
| 输入/数字/下拉 | 直角边界、紧凑内边距、可读数值；图标和值合组可以节省重复行。 |
| 开关 | 方形轨道与滑块，状态通过颜色和位置共同变化，使用真实可键盘操作的控件。 |
| 复选/单选/滑杆 | 黄色强调、可见值/选择，保留原生或等价键盘操作。 |
| 导航/标签页 | 扁平、简短、当前标记明确，避免巨大导航块。 |
| 面板/行 | 直角、中性、极少阴影，尽量共用分隔线而非层层加框。 |
| 状态标签 | 小型文字与语义信号，不只用彩色圆点。 |
| Tooltip/菜单 | 补充上下文而不增加常驻标签负担，普通 tooltip 不承载必要操作。 |
| 弹窗 | 相对任务保持紧凑，但文字可读、有界滚动、关闭/取消及明确确认。 |
| 空/加载/错误 | 保留原因和下一步，小界面不是省略状态的理由。 |

按实际功能选择控件，优先复用目标项目已有组件；本规范不绑定特定框架、组件库或 CSS 类名。

### 选择控件的取舍

| 场景 | 优先形式 | 规则 |
|---|---|---|
| 少量、短名称的多选一 | 分段单选 | 如关闭/开启、100%/110%/125%/150%；同组只能选一项，采用原生 radio 语义，不冒充标签页或多个独立开关。 |
| 选项较多、名称较长或横向放不下的多选一 | 单选下拉框 | 优先使用 `select`，不为展示全部选项而挤压界面。 |
| 少量多选 | 平铺复选框组 | 短标签横排，较长标签或窄区域竖排；每项独立勾选，允许同时选多项或全部不选。 |
| 多选较多或空间有限 | 下拉多选 | 展开后是复选框列表，不是单选菜单；勾选不自动关闭，触发器以固定单行显示已选数量，面板内部滚动。 |

分段轨道使用中性控件底，选中项使用信号黄派生底/边框/内侧标记，轨道与选项保持直角，不使用悬浮工具条的圆角变体。复选框与下拉多选沿用相同主题语义。

所有选择态必须保持几何稳定：不因勾选改变 padding、边框宽度、字号/字重、列宽或行高。选中线使用不占布局空间的内阴影/轮廓，或提前预留边框。只更新选择属性和状态样式，不因一次勾选重建整张表；批量操作使用既有区域，不突然插入一行推开列表。

### 可复制技术值

对于经常需要复制的 ID、端点、路径、命令或配置片段，在值旁提供低强调复制操作，不为所有文字都增加按钮。优先放在一条紧凑行中，不再增加标签或代码卡外壳；多行片段可以使用独立代码容器。操作沿用直角默认，值本身保持可读、可选择。

- 预留稳定的操作位，真实复制成功后短暂原位替换为勾号等反馈；不推动数值，不添加“点击复制”等说明，不为每次常规复制都弹 toast。
- 明确复制完整值还是显示/脱敏值，不得绕过产品权限暴露隐藏密钥。失败时在发生处提供必要短反馈，不把复制失败显示成成功。
- 提供可访问名称和键盘操作，成功/失败可被辅助技术获知，不只依赖图标。验证目标宿主的剪贴板能力，需要支持本地网页时包含 `file://` 场景。

### 紧凑数值步进器

需要反复微调的数值，可将减号、数值、加号组织在同一紧凑属性行中，适用时允许直接编辑，并将 `px`、`%` 等真实单位与值合组。保持直角基础控件，按场景使用 24px 工具上下文或约 28px 常规控件基准，不强迫阅读/设置字段小于可读尺寸。不替换所有原生数字输入或滑杆，不重复堆加步进按钮，不使用圆形增减操作。

- 由产品定义范围、步长、精度、空值语义及边界/越界行为；到达上限或下限时只禁用对应增减操作，不静默替换成任意默认值。
- 适用时保留原生数字输入语义、直接输入和键盘操作，增减按钮有可访问名称，不让整个组合只能靠鼠标操作小按钮。
- 为预期数字位数和单位预留宽度，增减、跨位数、聚焦或禁用时不改变组合尺寸、不推开相邻属性。单位是字段信息，不是额外解释段落。

### 核心控件状态配方

按控件实际行为使用下列状态，不要求每个控件具有全部状态。紧凑不意味着混同悬浮、按下、键盘焦点、选中和禁用；焦点可以与选中或错误并存。

| 控件 | 常态 | 悬浮/按下 | 持续状态或错误 | 键盘焦点 | 禁用/加载 |
|---|---|---|---|---|---|
| 操作按钮 | 按主操作、中性或破坏性配方，默认直角 | 派生表面/边框；主按钮使用黄派生悬浮/按下色 | 只有真实切换按钮使用持续按下态，不把一次操作完成画成选中 | 可见的 2px 信号轮廓 | 次级但可读的控件，阻止不可用操作；真实加载预留反馈空间 |
| 文字/数字/下拉输入 | 控件底、可见直角边界与标签 | 不位移、不改变 padding | 只读仍可选取；无效有危险边界和必要的就近错误 | 信号边界与可见轮廓；错误仍可辨 | 可读但不可用；只读不等于禁用 |
| 复选/单选/开关 | 可辨认的原生或等价控件；开关为方轨道/滑块 | 命中区域与几何保持稳定 | 勾号、圆点或滑块位置配合信号色 | 实际控件上的焦点可见 | 不可操作但不抹去当前值；不虚构通用加载态 |
| 分段单选 | 中性直角轨道，预留边框，各项处理一致 | 控件悬浮面，字重稳定 | 选中项使用信号弱底、信号边框和内侧标记 | 可见分段上的轮廓 | 次级但可读，不可通过禁用项改变选择 |
| 数据行 | 稳定列与中性连续表面 | 只改变悬浮表面 | 复选/标记配合选中表面或内侧边线 | 实际交互单元/控件上的焦点可见 | 只禁用不可用操作，保留行内容 |
| 菜单/下拉多选 | 中性触发器，面板关闭 | 交互行悬浮但不位移 | 展开触发器有信号边界；勾选项保留勾号与弱底 | 触发器/选项焦点可见，Escape 返回触发器 | 不可用项不能执行；不把无结果混同加载 |

边框、padding、字号/字重、行高与反馈位在这些状态之间保持几何稳定。检查深浅色和减少动效下实际使用的状态组合，不为填满状态矩阵而虚构控件行为。

## 8. 交互契约

- 可见的 2px 信号焦点与合理 Tab 顺序不可省略。
- 纯图标控件有可访问名称；相关 tooltip 是补充，不替代名称。
- 真正的标签页支持左右方向键、Home/End，只有当前标签进入普通 Tab 序列。
- 分段单选保留原生 radio 的方向键和单个 Tab 入口；复选框使用 Tab/Space。下拉多选支持 Enter/Space 展开、Tab 到选项、Space 勾选，Escape 关闭并回到触发器；外部点击关闭，展开面板不参与页面排版。
- 模态框支持 Escape、初始/受限焦点、背景滚动锁定和焦点恢复。
- 菜单支持 Escape、外部交互关闭，折叠保持键盘可操作。
- 激活、悬浮、选中、禁用、无效和加载态即使在小表面上也必须不同。
- 宽度稳定，局部滚动，属性出现时避免布局跳动。
- 状态过渡采用 150–200ms；必要的较复杂展开可使用 300ms。不做持续装饰动画，尊重 `prefers-reduced-motion`。
- 不为省空间删除权限、标签、错误、撤销/取消语义和真实字段。
- 状态反馈与真实操作结果一致，不把未执行或失败的操作显示为成功。

## 9. 浅色模式

| 角色 | 浅色值 |
|---|---|
| 主背景/表面/面板 | `#edf1e4` / `#f8faf3` / `#ffffff` |
| 侧栏 | `#e4e9dc` |
| 控件/悬浮 | `#f1f4ea` / `#e7ecdf` |
| 正文/次级文字 | `#10150e` / `#5d6659` |
| 细分隔线 | `rgba(16, 21, 14, 0.16)` |

保留基础强调色，通过混入深色正文加深强调文字：黄 34%，绿/蓝 52%，红 68%。仅切换配色，保持既有密度、直角几何和信息层级。

宿主产品刻意固定为深色的画布可以是独立渲染上下文，不能据此忽略周围控件的浅色模式。

## 10. 禁止方向

不增加巨大圆角、宽阔装饰间距、玻璃模糊、悬浮发光、大型装饰标题、重复卡片壳层，或与当前对象重复的常驻标签。不把可直接阅读的内容或属性拆成等权指标卡片墙。

减少空间浪费不等于取消必要间距或可读的长文本区域。悬浮工具条可使用命名的圆角变体，阅读和设置区域可采用更宽松的密度。

## 11. 可直接使用的实现提示词

> 文案约束：不添加装饰性英文眉题、全大写微标签或口号副标题。默认不添加解释性文案，不重复解释含义清楚的按钮和字段；仅保留理解任务、避免错误或风险所必需的简短提示、字段标签和可访问名称。

> 选择约束：少量短选项的单选可用主题色分段 radio，选项多或放不下时优先下拉；多选使用横/竖排复选框组，或展开复选框列表的下拉多选。勾选只改变状态，不改变控件几何、重建整张表或推开列表。

> 细节约束：按任务需要提供技术值就地复制及真实反馈、带明确单位/边界且宽度稳定的紧凑数值步进器；确有长表比较时在局部滚动中保留表头，不给小列表增加外壳；检查预览保持内容保真。数据变化方向不等于成功/失败。深浅色均遵循适用的控件状态配方，不为满足配方而新增非必要控件或业务能力。

> 为目标界面应用 neuro-mini 主题，不改变其业务定义或功能范围。使用准确的近黑中性配色、信号黄激活/主操作/焦点、绿色身份/成功、青色信息和红色危险。默认直角基础控件、细边界、少阴影。先简化结构、容器和重复标签来省空间，不先缩小文字，不使用全局缩放。按内容采用 24px 工具上下文、约 28px 常规控件，以及可读的 36px 设置字段。界面使用系统字体，技术值使用等宽字体。布局由内容决定，不强制添加工具栏、侧栏或检查器。常用属性靠近其影响对象，高级控件按需展开。独立悬浮工具条可使用 9px/5px 圆角变体，不推广到基础控件。保留必要标签、权限、键盘、Escape、焦点恢复、真实状态、局部滚动、窄屏和减少动效，复用项目已有组件。
